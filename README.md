# Geo-Spatial Visualization for Disaster Monitoring

## Overview
This application allows users to monitor and visualize disasters in real-time through the analysis of news articles. It provides a comprehensive overview of ongoing and past disaster events.

## Features
- Interactive Map Visualization
- Filtering Options
- Insights and Analytics
- Key Events Marquee
- Dynamic Updates

## Technologies Used
- Python
- Streamlit
- Pandas
- Folium
- Plotly
- MongoDB
